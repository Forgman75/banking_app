# Банковская аналитика

Консольное приложение для просмотра банковской аналитики: главная страница, страница событий, категории кэшбэка, инвестиционный банк, поиск, а также отчеты по расходам.

Проект построен как интерактивное меню, состав которого формируется динамически на основе настроек пользователя.

---

## Возможности

- Динамическое меню: показываются только включенные функции.
- Поддержка автозапуска выбранных разделов при старте программы.
- Поддержка пользовательских настроек через `load_user_settings()`.
- Подключение внешних аналитических функций:
  - `cashback_categories`
  - `investment_bank`
  - `simple_search`
  - `phone_search`
  - `spending_by_category`
  - `spending_by_weekday`
- Универсальный вызов функций с разными сигнатурами.
- Централизованная обработка ошибок.
- Логирование ошибок через модуль `logging`.

---


Файл `main.py` содержит основную логику приложения.

## Установка

1. Склонируйте или скопируйте проект.

```bash
git clone <repository-url>
cd banking_app
```

2. При необходимости создайте виртуальное окружение:

```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:

Для Windows:

```bash
venv\Scripts\activate
```

Для Linux/macOS:

```bash
source venv/bin/activate
```

4. Установите зависимости:

```bash
poetry install
```

## Запуск

```bash
python main.py
```

После запуска программа:

1. Загрузит настройки пользователя.
2. Построит меню из включенных функций.
3. Выполнит функции с флагом `auto_run`, если они включены.
4. Запустит интерактивный режим ожидания выбора пользователя.

## Настройки

Настройки могут возвращаться функцией `load_user_settings()`.

Ожидаемый формат:

```json
{
  "features": {
    "home_page": {
      "enabled": true,
      "auto_run": false,
      "title": "Главная страница"
    },
    "events_page": {
      "enabled": true,
      "auto_run": false,
      "title": "Страница событий"
    },
    "cashback_categories": {
      "enabled": true,
      "auto_run": false,
      "title": "Категории кэшбэка"
    },
    "investment_bank": {
      "enabled": true,
      "auto_run": false,
      "title": "Инвестиционный банк"
    },
    "simple_search": {
      "enabled": true,
      "auto_run": false,
      "title": "Простой поиск"
    },
    "phone_search": {
      "enabled": true,
      "auto_run": false,
      "title": "Поиск по телефону"
    },
    "spending_by_category": {
      "enabled": true,
      "auto_run": false,
      "title": "Отчет: расходы по категориям"
    },
    "spending_by_weekday": {
      "enabled": true,
      "auto_run": false,
      "title": "Отчет: расходы по дням недели"
    }
  }
}
```

---

## Описание параметров настроек

### `enabled`

Определяет, доступен ли раздел в меню.

```json
"enabled": true
```

Если `false`, раздел не отображается и не может быть вызван.

---

### `auto_run`

Определяет, нужно ли автоматически запускать раздел при старте программы.

```json
"auto_run": true
```

Если `true`, при старте программа автоматически выполнит соответствующий раздел.

Пример:

```json
{
  "features": {
    "home_page": {
      "enabled": true,
      "auto_run": true
    }
  }
}
```

При таких настройках программа сразу запустит генерацию главной страницы.

---

### `title`

Задает отображаемое название раздела в меню.

```json
"title": "Моя аналитика"
```

Если параметр не указан, будет использовано название по умолчанию.

## Используемые функции

Проект рассчитывает на наличие следующих функций.

### Обязательные базовые функции

| Функция | Назначение |
|---|---|
| `load_user_settings()` | Загружает пользовательские настройки |
| `get_user_date_input()` | Запрашивает у пользователя дату |
| `generate_home_page(date_str)` | Генерирует главную страницу |
| `generate_events_page(date_str, period=...)` | Генерирует страницу событий |

---

### Дополнительные аналитические функции

| Функция | Назначение |
|---|---|
| `cashback_categories(...)` | Категории кэшбэка |
| `investment_bank(...)` | Инвестиционный банк |
| `simple_search(...)` | Простой поиск |
| `phone_search(...)` | Поиск по номеру телефона |
| `spending_by_category(...)` | Отчет по категориям расходов |
| `spending_by_weekday(...)` | Отчет по дням недели |

---

## Периоды

Для функций, использующих период, поддерживаются следующие значения:

| Значение | Описание |
|---|---|
| `W` | Неделя |
| `M` | Месяц |
| `Y` | Год |
| `ALL` | Весь доступный период |

Если пользователь не вводит период, по умолчанию используется `M`.
